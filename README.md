# 💳 Cards Data Analysis Dashboard

An interactive Power BI dashboard that analyzes card-related data to uncover trends in card issuance, card brands, card types, and credit limits. The dashboard provides dynamic visualizations and actionable insights to support data-driven decision-making.

---

# 📖 Short Description

The **Cards Data Analysis Dashboard** is a Power BI project developed to transform raw card data into meaningful business insights. It enables users to analyze card issuance trends, compare different card brands and card types, monitor credit limits, and explore the data through interactive visualizations and filters.

This project demonstrates how Power BI can simplify complex datasets and present valuable insights through an intuitive dashboard.

---

# 🛠 Tech Stack

The dashboard was built using the following tools and technologies:

- 📊 **Power BI Desktop** – Dashboard development and visualization
- 📂 **Power Query** – Data cleaning and transformation
- 🧠 **DAX (Data Analysis Expressions)** – Calculated measures and KPIs
- 📑 **Microsoft Excel** – Source dataset
- 📈 **Data Modeling** – Relationships between tables for interactive analysis
- 📁 **File Formats** – `.pbix`, `.xlsx`, `.png`

---

# 📂 Data Source

**Source:** Microsoft Excel Dataset

The dataset contains information related to:

- Card Brand
- Card Type
- Card Category
- Credit Limit

- Customer Information
- Other card-related attributes

# 🌟 Features & Highlights

## 📌 Business Problem

Financial institutions generate large volumes of card-related data, making it difficult to identify trends and monitor card performance using spreadsheets alone.

Organizations require interactive dashboards to analyze card issuance, compare brands, monitor credit limits, and gain business insights efficiently.

---

## 🎯 Goal of the Dashboard

The primary objective of this dashboard is to:

- Analyze card issuance trends.
- Compare different card brands.
- Analyze card types and categories.
- Monitor credit limit distribution.
- Enable interactive data exploration.
- Support business decisions through visual analytics.

---

## 📊 Walkthrough of Key Visuals

### 📌 KPI Cards

The dashboard provides quick business metrics including:

- Total Cards Issued
- Average Credit Limit
- Number of Card Brands
- Number of Card Types

These KPIs offer a quick overview of the dataset.

---

### 📅 Card Issuance Analysis

A column chart displays the number of cards issued each year, helping identify issuance trends over time.

---

### 💳 Card Type Analysis

A donut chart visualizes the distribution of different card types, such as:

- Credit Card
- Debit Card
- Debit Prepaid Card

---

### 🏦 Card Brand Analysis

A bar chart compares the number of cards issued by different brands, including:

- Visa
- Mastercard
- American Express
- Discover

---

### 💰 Credit Limit Analysis

A line chart illustrates the average credit limit across different card brands, helping users compare financial offerings.

---

### 🎛 Interactive Filters

Users can explore the dashboard using filters such as:

- Card Type
- Card Brand

These slicers provide customized and interactive analysis.

---

### 📋 Detailed Data Table

A detailed table displays complete card-related information for in-depth exploration and validation.

---

# 📈 Business Insights

Some key insights obtained from the dashboard include:

- Visa and Mastercard dominate the card market.
- Card issuance trends vary across different years.
- Credit limits differ significantly between card brands.
- Different card types have unique distribution patterns.
- Interactive filters improve analytical flexibility.
- KPI cards provide a quick summary of important business metrics.

# 💼 Business Impact

This dashboard helps:

- Financial institutions monitor card issuance performance.
- Business analysts identify card usage trends.
- Marketing teams understand customer preferences.
- Decision-makers evaluate credit limit distribution.
- Organizations make data-driven decisions using interactive analytics.
